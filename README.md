# 🌊 Farmacia Marina: Simulador Molecular Cuántico (VQE)

Aplicación web interactiva de biotecnología azul basada en **IBM Qiskit** que utiliza el algoritmo híbrido **VQE (Variational Quantum Eigensolver)** para evaluar la estabilidad energética de compuestos bioactivos marinos. Permite analizar extractos de referencia del Mediterráneo, ajustar parámetros manuales o procesar lotes completos de laboratorio en formato **CSV / Excel**.

🔗 **Prueba la aplicación en vivo aquí:** https://farmacia-marina-vqe.streamlit.app/

## 🧬 Funcionalidades principales
* **Catálogo de Referencia:** Simulación inmediata de alcaloides, péptidos y polifenoles marinos.
* **Control Numérico Manual:** Ajuste libre de la energía base y la fuerza de interacción cuántica (`XX`).
* **Procesamiento en Lote (CSV / Excel):** Carga de tablas de laboratorio con plantilla descargable y generación automática de ranking de estabilidad molecular.
